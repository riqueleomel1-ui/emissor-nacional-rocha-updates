# Emissor Nacional Rocha - Atualizacoes

Repositorio publico usado exclusivamente pelo atualizador automatico do **Emissor Nacional Rocha**.

- `version.json`: informa a versao mais recente.
- `releases/`: recebera os pacotes das proximas atualizacoes.

Este repositorio **nao armazena certificados digitais, senhas, dados de clientes ou configuracoes locais**.
